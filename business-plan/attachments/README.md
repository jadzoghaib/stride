# Attachments

Image slots referenced by `../stride-business-plan-draft.md`. Each embed in that
document carries alt text describing what belongs there and what argument the
image is making — drop files in with these names and they resolve.

| File | What it is |
|---|---|
| `hero-trail-runner.jpg` | Opening image. One athlete small in a large landscape: scale |
| `athlete-portrait.jpg` | A real niche athlete at an ordinary event. Caption with sport, ranking, follower count |
| `product-matching.png` | The matching screen, a row expanded, score components visible. Screenshot from the demo at `/sponsor/campaigns/1` |
| `race-expo.jpg` | A race expo or tournament village. The argument is density: everyone in frame is a practitioner |

Obsidian resolves these relative to the note, so the folder can move with it.
